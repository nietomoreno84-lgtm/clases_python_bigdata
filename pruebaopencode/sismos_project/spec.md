# Proyecto EDA de sismos en python con jupyter notebook
## Objetivo 
    - Quiero generar un fichero .ipynb de jupyter notebook analizando los datos de una BBDD en mongodb
    - El objetivo primero es extraer los datos de la bbdd el local de mongo Compass
    - El objetivo segundo es trasladar la informacion a un dataframe para poderlo manejar.
    - El objetivo tercero seria limpiar la informacion del dtaframe obtenido, de duplicados , nulos y valores incongruentes.
    - El objetivo final es mostrar la informacion en graficas de los siguientes puntos:
        - Sismos mas potentes ocurridos en el mundo segun su escala
        - Ciudades que mas sismos sufren a lo largo del tiempo.
        - Mapa coropletico con las zonas mas sismicas del planeta.

# Resultado final
    - Un fichero con extension .ipynb comentado con markdown y conclusiones de los graficos pedidos.
